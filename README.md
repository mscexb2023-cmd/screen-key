# Ключ-Наушники (Screen Key)

Приложение для Android с тремя режимами защиты экрана (шторка «🔒 Контент скрыт»
накрывается мгновенно и снимается, когда условия выполнены):

1. **Ключ** — экран виден **только пока подключены наушники**. Вытащили провод
   (3.5 мм / USB-C) или отключили Bluetooth — весь экран накрыт шторкой.
2. **Инверсия** — наоборот: шторка, **пока** наушники подключены
   («воткнул → блюр, вытащил → норм»).
3. **Фронтальный замок** — фронтальная камера проверяет, что **ровно одно лицо
   держит экран строго напротив себя**: отвернулись, положили телефон на столик,
   кто-то его взял, наклонили, в кадр попало второе лицо — мгновенный блюр.
   Вернули в правильное положение — экран вернулся. Дополнительно можно
   требовать и наушники (галочка «также требовать наушники»).

Все пороги (поворот/наклон головы, зона центра, скорость срабатывания) и все
тексты шторки редактируются пользователем в разделе **«Параметры»** и применяются
к работающей защите сразу. Кнопка **«Проверить шторку»** показывает её на 3 секунды
для проверки без реальных условий.

описание, политика конфиденциальности, чек-лист модерации и шаблоны ответов —
в файле [RUSTORE-LISTING.md](RUSTORE-LISTING.md).

## Что нужно

- Android 8.0 или новее
- Разрешение «поверх других окон» (приложение предложит открыть настройку)
- Для «Фронтального замка» — разрешение на камеру

## Как это работает внутри

- Сервис `KeyService` — постоянный фоновый сервис:
  - слушает `AudioDeviceCallback`: система сообщает приложению в момент
    физического подключения/отключения любого аудиоустройства;
  - в режиме «Фронтальный замок» запускает CameraX + ML Kit (модель вшита в APK,
    Google-сервисы не нужны) через `FaceAnalyzer`: ровно одно лицо, по центру,
    повороты головы в пределах порогов (18°/25°); гистерезис 3–4 кадра, чтобы
    шторка не мигала;
  - реакция — полноэкранное окно `TYPE_APPLICATION_OVERLAY`, блокирует касания.
- Автозапуск при включении телефона — `BootReceiver` (галочка в настройках).

## Честные ограничения

1. **Шторка закрывает/открывает экран для всех сразу.** Телефон не умеет
   показывать «владельцу чётко, соседу размыто» — ни наушник, ни камера не меняют
   физику света. «Фронтальный замок» защищает от чужих рук и от «отвернулся /
   положил телефон», но **не** от соседа, который подсматривает сбоку, пока вы
   смотрите нормально: его лицо вне поля зрения фронтальной камеры.
2. Датчик «наушник именно в ухе» обычным приложениям недоступен — используются
   события подключения/отключения разъёма или Bluetooth.
3. Шторка — матовая панель, а не пиксельное размытие чужих приложений.
4. «Фронтальный замок» постоянно держит фронтальную камеру включённой:
   в статус-баре будет зелёная точка (индикатор камеры Android), батарея
   расходуется заметнее. В темноте и в тёмных очках распознавание хуже.
5. Смена режима радио-кнопкой сразу включает защиту (служба стартует сама).

## Сборка APK бесплатно, без Android Studio (GitHub Actions)

1. Создайте аккаунт на github.com (если нет).
2. Создайте новый **публичный** репозиторий, например `screen-key`.
3. Загрузите в него **всё содержимое этой папки** (включая вложенную `.github/workflows/build.yml`
   — в веб-интерфейсе папка `.github` создаётся кнопкой «Create new file»: введите
   `.github/workflows/build.yml`).
4. Откройте вкладку **Actions** → выберите `build-apk` → **Run workflow**.
5. Через ~3–5 минут в завершившейся сборке появится артефакт `screen-key-debug-apk` —
   скачайте (zip с `app-debug.apk` внутри).
6. Перекиньте APK на телефон, откройте, разрешите «установку из неизвестных источников» — готово.

## Сборка локально (Android Studio)

Открыть папку проекта → Build → Build APK. Нужно ~6 ГБ места и установленный Android Studio.

## Настройка на телефоне после установки

1. Откройте приложение → «Разрешить показ поверх других окон» → включите тумблер → вернитесь.
2. Выберите режим радио-кнопкой; для «Фронтального замка» разрешите камеру.
3. «Запустить защиту».
4. Чтобы Android не убивал сервис: Настройки → Приложения → Ключ-Наушники →
   Батарея → «Без ограничений».
5. Проверка: подключите/отключите наушники — шторка должна мгновенно уходить/приходить;
   в «Фронтальном замке» отведите телефон в сторону — шторка, верните напротив лица — уходит.
